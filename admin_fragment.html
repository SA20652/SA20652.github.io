🧹 Очистка пустых аккаунтов

Удаляет из базы только аккаунты без кубов: ≤ 1 000 монет, до 3 открытых кейсов, уровень ≤ 1, без побед/поражений, Premium и админ-доступа. Действие необратимо.

🗑️ Удалить последних зарегистрированных

Удаляет N самых новых аккаунтов по дате регистрации. Действие необратимо.
